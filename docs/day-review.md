# Day review workspace

Days needing attention uses one selectable row per employee/day, with consecutive
missing dates kept as a range. Multiple findings share the selected day detail pane;
individual findings expand there. Imported-day navigation is deduplicated per day.
A missing range retains its one vacation request and individual-date correction actions.

Needs review, Import proposals and Information & history are separate categories.
The latter includes historical import checks so these do not bury reconstruction
proposals. Category badges count distinct employee/day pairs, not findings or groups.
Search, employee, issue-type and date filters apply before grouping. The list displays
ten groups per page. Desktop uses two panes; phone stacks a bounded list and detail.

Existing resolution callbacks preserve the employee, original issue and prepared
request. Read-only accounts can inspect source history but cannot prepare mutations.
No findings, import evidence, balances or approval rules change through this UI update.
The older “Initial import review and proposals” section is now represented by the
Import proposals and Information & history tabs.
